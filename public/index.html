Criterios de diseño explícitos

La industria, el estilo, la paleta y el símbolo se envían al modelo como instrucciones. Así puedes probar cuánto respeta cada restricción sin entrenar un modelo propio.

Imagen generada, no SVG nativo

El modelo devuelve imágenes PNG. Puedes descargarlas y, en una etapa posterior, vectorizarlas; la conversión automática a SVG puede requerir limpieza manual.
